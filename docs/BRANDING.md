# ngodik Brand Assets

## Concept

The Progress N mark uses a custom lowercase n-shaped path with an amber endpoint. It connects the product name's opening letter with the idea of moving a project from an initial thought toward a usable blueprint.

## Palette

| Token | Hex | Use |
| --- | --- | --- |
| Charcoal | #1B1D21 | Primary mark, wordmark, and dark app tile |
| Paper | #EEEEF0 | Reversed mark and text on dark surfaces |
| Amber | #ECA94B | Progress endpoint and small accent |

Amber is an accent for the mark. Do not use it for small text on a white background where contrast is insufficient.

- ngodik-horizontal-white.svg: reversed lockup for dark backgrounds
- ngodik-symbol-black.svg, ngodik-symbol-white.svg, ngodik-symbol-mono-eca94b.svg: one-color variants
- ngodik-symbol-square.svg: square social/avatar variant
- ngodik-symbol-favicon.svg: simplified small-size variant
- ngodik-app-icon.svg and ngodik-app-icon.png: app tile
- src-tauri/icons/icon.ico: multi-resolution Windows icon
- public/favicon.ico and public/favicon.png: browser tab icons

## Usage

Use the horizontal lockup on light surfaces and the reversed lockup on dark surfaces. Use the app icon only for square contexts such as the app launcher or avatar. Keep clear space around the mark at least equal to the width of the N stem. Do not redraw, recolor the progress point, add effects, or stretch the artwork. Keep the small-size favicon variant for 16 to 32 px contexts.

The wordmark is outlined as SVG paths from Inter Variable. The font file and its SIL Open Font License notice are included through the frontend dependency at public/licenses/inter.txt.
